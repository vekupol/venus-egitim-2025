# 🚀 Venüs Eğitim ve Koçluk Platformu  

Venüs Eğitim; matematik eğitimi, öğrenci koçluğu ve eğitim teknolojilerini bir araya getiren bir web platformudur. Bu proje, **React.js** ve **Firebase** kullanılarak geliştirilmiştir.  

🔗 **GitHub Repo:** [https://github.com/vekupol/venus-egitim-2025](https://github.com/vekupol/venus-egitim-2025)

---

## ✨ Özellikler  
- 🎓 **Matematik eğitimi** için konu anlatımları ve etkileşimli içerikler  
- 🧑‍🏫 **Öğrenci koçluğu** ve bireysel takip sistemi  
- 🔥 **Firebase** ile kimlik doğrulama (Auth) ve veritabanı (Firestore)  
- 💾 Gerçek zamanlı ilerleme takibi ve kullanıcıya özel veriler  
- 🎨 **Adobe animasyonları** ile desteklenmiş ders içerikleri  
- 📊 İlerleme grafikleri ve başarı sıralamaları  

---

## 🛠 Kullanılan Teknolojiler  
- **React.js (Hooks & Functional Components)**  
- **Firebase (Auth, Firestore, Storage)**  
- **Styled Components**  
- **React Router**  
- **Chart.js (Grafikler için)**  
- **Adobe Creative Cloud (Premiere, After Effects, Animate)**  

---

## 📦 Kurulum  
Projeyi kendi bilgisayarında çalıştırmak için:  
```bash
# Repoyu klonla
git clone https://github.com/vekupol/venus-egitim-2025.git

# Proje dizinine gir
cd venus-egitim-2025

# Gerekli paketleri yükle
npm install

# Geliştirme sunucusunu başlat
npm start
